Canonical Genealogy Charter

بِسْمِ اللَّهِ الرَّحْمَنِ الرَّحِيمِ

Preamble

This Charter establishes the canonical governance framework for the Sadat Lineage Archive, binding all State Admins, Super Admins, contributors, and users.

Article 1 — Canonical Sources

  1. Primary Sources: Tarikh Anwar-us-Sadat, Tarikh Sadat-e-Barha (Vol I & II), Tarikh Sadat-e-Amroha, Shajra Nasab Sadat Barha.
  2. Supplementary: Verified manuscripts, waqf records, sanad chains with isnad.
  3. Hierarchy: Primary > Supplementary > Oral tradition (with isnad).

Article 2 — Verification Standards

  1. Father-to-son chain required for each generation.
  2. Source citation mandatory: Book + Page + Line.
  3. Cross-referencing with at least one other primary source.
  4. State Admin verification required before public entry.

Article 3 — Privacy Governance

  1. Living individuals: Only canonical fields public (name, father, generation, branch, source).
  2. Contact data: Never stored in public view. Encrypted at rest.
  3. Matrimony: Wali approval required for any disclosure.
  4. Right to be forgotten: Applies to non-canonical fields only.

Article 4 — Governance Structure

RoleAuthority
Canonical BoardCharter amendments, source authentication
Super AdminCross-state governance, audit, emergency powers
State AdminSubmission verification, matrimony Wali approval, regional governance
ContributorSubmit records, suggest corrections

Article 5 — Canonical Integrity

  1. No record modified without audit trail.
  2. Conflicts resolved by earliest primary source.
  3. Doubtful lineages marked "Unverified" until resolved.
  4. Annual canonical audit by Super Admin panel.

Article 6 — Dispute Resolution

  1. Lineage disputes → State Admin review → Canonical Board appeal.
  2. Cross-state disputes → Super Admin mediation.
  3. Final authority: Canonical Board (unanimous decision).

Article 7 — Amendments

Charter amendments require: Canonical Board unanimous vote + Super Admin ratification + 30-day public notice.

Canonical Maxim: "Truth in lineage is a trust (amanah). Governance is its shield."

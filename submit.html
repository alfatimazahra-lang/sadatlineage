What Happens After Submission?

  1. Queue Assignment: Record routed to State Admin based on location.
  2. Canonical Verification: Admin cross-references with source books (Tarikh Anwar-us-Sadat, Sadat-e-Barha, etc.).
  3. Generation Mapping: Paternal lineage traced to existing canonical records.
  4. Approval/Rejection: Status updated with reference code. Applicant notified.
  5. Public Entry: Approved records appear in Archive search (privacy fields hidden).
